# Avdb Magic Tools 更新日志

本日志记录插件的用户可见变化。插件通过独立 DLL 和发布清单更新；AVDB 应用 OTA 不会替换 Emby 中的插件。安装和配置见 [使用说明](README.md)，公开文件见 [发布目录](https://github.com/li-peifeng/AVdb-Only/tree/main/Avdb-Magic-Tools)。

## 2026.11.26.231 · 2026-11-26

- 「使用 NGi 刮削」会把 Emby 已识别的 CD1、CD2 等分集一起提交为一条手动任务。整组提交需要使用支持分集提交的 NGi。

## 2026.11.13.230 · 2026-11-13

- 新增 NGi NFO 原片大小接口，AVDB 可通过现有 Emby 地址和管理员 API 密钥读取 STRM 原片大小，用于“已入库”资源版本匹配，无需向 AVDB 映射或挂载媒体目录。
- 读取时核对 STRM 文件名、内容摘要和 NFO 中的大小记录；Emby 合并版本分别返回大小，不把多个版本相加。缺少或未通过校验的记录保持未知，不把 STRM 文本文件大小当作原片大小。
- 功能只读取 Emby 已能访问的 STRM 和 NFO，不请求播放链接、不探测原视频，也不改写媒体文件。需要 NGi 先生成带原片大小的 NFO，并在更新插件或 NFO 后刷新 AVDB 的 Emby 媒体库镜像；不依赖“STRM 媒体信息预提取”任务。

## 2026.11.6.229 · 2026-11-06

- 修复“使用 NGi 刮削”已经提交任务却收不到有效结果的问题。
- 提交时显示连接、鉴权、路径及 NGi 返回的具体错误，便于排查地址和目录映射。超时后应先查看 NGi 手动任务，避免重复提交。

## 2026.11.6.228 · 2026-11-06

- 新增管理员“使用 NGi 刮削”菜单，可从 Emby Web 单个视频的右键、长按或更多菜单提交 NGi 手动任务。
- 新增独立的 NGi 网页地址、联动密钥和目录映射设置。联动仅允许在 NGi 配置的目录内原地刮削，保留视频路径及文件名，任务结果在 NGi 查看。
- 支持提交 STRM 文件本身；提交成功表示任务进入队列，完成后由用户在 Emby 刷新元数据。

## 2026.10.9.227 · 2026-10-09

- 新增 Emby 原生演员图片来源 **Jalbum.Avdb**，可在“修改图片”中从演员写真选择头像。
- 与 **Gfriends.Avdb** 共用演员头像来源开关和 AVDB 连接配置，独立于演员写真区域的显示开关；没有候选时保留现有头像。

## 2026.10.5.226 · 2026-10-05

- 影片剧照按文件名自然排序，例如 `fanart2` 排在 `fanart10` 前；保留原 Backdrop 索引、主背景及图片覆盖规则。
